closing advice that has been converted from PDF to Markdown.

- Return exactly ONE object that matches the schema.

- Normalise every date to ISO format YYYY-MM-DD (e.g. '30/Jun/2026' -> '2026-06-30').
- Share percentages should be without % sign: '3%' -> 3
- Include EVERY row of the balance table, including zero or 'Not Advised'
  lines (use 0 when clearly zero, null when truly unknown).
- Never invent values. If a field is not on the page, leave it null.
